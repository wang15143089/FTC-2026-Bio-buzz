## 4. 核对结果

### 4.1 pass（版本正确 / 几何正确）

1. **桌面 R37 文件 = 仓库 R37 文件 = R005 所测文件**（SHA256 `80CB3ED05CED…E36B1966` 三者相同）⇒ 版本正确、非旧副本。
2. **R005 几何检验 4/4 pass**：托板右端 215.2615（目标 215 ± 0.5）、飞轮组 z 上限 338.7996（目标 338.8 ± 1.0）、
   体积 930299.217（目标 930299.902，相对偏差 1e-6）、根实体 23（不得丢失/合并）。
3. **本轮独立复算一致**：16 部件体积合计 930299.1 mm³（发布值 930299.9）；拨杆轴心实测 (29.49, 0, 111.46)
   与 KNOWN 值零偏差；轮轴距 161.60 / 179.60 = 2 × 80.8 / 2 × 89.8；冷热夹口关系成立。
4. **交付件回读一致**：`T06_motion_*.step` 各 25 根实体、948918.082 mm³、包围盒 z 上限 333.259 / 338.800，
   与 16 件 + 2 贴带件之和相符（930299.1 + 18618.8 = 948917.9）。
5. **R39 内衬单体 5/5 pass**（内弧偏移 +0.4876、外弧 −0.0002、托板面 −0.4608、扇区 142.0–275.0°）。

### 4.2 版本不一致（CAD 未跟上已验收的仿真口径）

| # | 项 | CAD 现值（来源） | 最新口径（来源） | 状态 |
|---|----|-----------------|-----------------|------|
| F1 | 托板右端 | **215.0**（S4 / DEC-0035） | **460**（S10 / DEC-0044 验收）；中途另有 350（DEC-0042 R44，亦未落地） | `fail`（未落地） |
| F2 | 竖向全宽挡舌 | **CAD 中不存在该零件**（S4 的 13 个自制件无 gate；`cad/*.py` 无生成器） | x = 180 mm、z 47.5↔139.5（S9 / DEC-0043） | `fail`（缺件） |
| F3 | 贴带区 | CAD 无贴带；R39 下料带扇区为 **142°→275°**（S5） | 实测贴敷区 **135°→258°** + 托板顶面（S10） | `fail`（未落地 + 扇区口径不同） |
| F4 | 参数主数据 | `config/parameters.yaml` 最新 T06 块 = `t06_liner_r39`（S5） | R40–R47 全部决策无参数条目 | `not_run` |

**判读要点**：F1–F3 都**不是** CAD 几何错误，而是「CAD 版本落后于仿真版本」。R47 的
6/6 全清 / 24/24 真出膛**依赖挡舌**，因此当前 CAD 不能被当作已验证机构的可制造版本。
另注：R39 的「打印件预缩 0.5」与 DEC-0044 的「不需要预缩」（0.2/0.5 mm 带厚对节拍无影响）
只是可选性差异，不是错误；本交付件采用**设计面**（R_IN = 107.974）+ 贴带标注件。

### 7.4 本轮修掉的隐患

舵机联轴器原先用 `Shape.mirror("XZ")` 定姿态 —— 那是绕**世界** XZ 平面镜像，把件搬到
y −105 … −88（马达侧）、与舵机完全不接。改为「平移到原点 → 绕自身 X 直径翻转 180° →
平移回位」后落在 y 88.00 … 105.00（REX 通孔 88…96 套住止于 96.0 的拨杆轴端，
25T 花键孔 102.1…105.0 咬住 101.5 起的舵机花键）。**R50 之前的 JSON / STEP 带这个错，
本轮已重刷。**
