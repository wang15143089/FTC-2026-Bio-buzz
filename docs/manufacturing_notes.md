# 制造说明

当前状态：用户明确“不对制造设备做要求”。因此不把任何特定设备作为硬约束；每个候选方案必须列出所需工艺、精度、外包依赖和替代工艺，之后再比较可实现性。

## 已知规则

- 名义尺寸与制造公差/配合分离管理。
- M3 前不加入非必要圆角、外观细节、螺纹或高细节紧固件。
- M8 发布必须包含版本化 CAD、必要图纸、BOM、材料/工艺、关键检验尺寸和装配顺序。
- 商业件早期使用轻量代理；最终以核验的供应商图纸和零件号为准。

## 待确认

- 3D 打印机成形范围、材料、喷嘴/层高和实测精度。
- CNC、车铣、激光/水刀、折弯和手工设备能力。
- 可采购材料规格、紧固件系列和交期。
- 团队可稳定检验的尺寸与量具能力。
