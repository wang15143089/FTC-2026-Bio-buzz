# 制造说明

## T04-C04B1-M3-0.3 验证件（非制造发布）

- `KNOWN` 三个打印件为官方4孔位舵机/导轨支架、17 mm节圆半径卷线鼓、25°楔形拨杆滑块；STEP/STL由同一CadQuery脚本生成。Fusion 360装配另包含官方舵机和铝舵盘实体。
- Fusion 360使用`exports/step/t04_c04b1_fusion360_assembly_m3.step`；单位为mm，导入后应出现5个命名组件。STEP只保存固定装配位置，不包含Fusion原生Joint、运动限制或参数时间线。
- `ASSUMED` 模块级单边打印间隙为0.30 mm，仅为首件起点；未指定材料、喷嘴、层高或收缩补偿，打印前应做局部间隙试片。
- 支架建议大底面朝下；卷线鼓法兰朝下；滑块方向由实际材料的桥接能力决定，底部12.6 mm导槽可使用可移除支撑。以上是起始建议，不是已验证工艺。
- 卷线鼓不得直接打印25T花键；必须使用REV-41-1828铝舵盘。中心孔仅用于接近原厂中心螺钉，任何进入舵机输出轴的M3螺钉不得超过官方6 mm深度。
- 使用约1 mm低伸长绳、全行程回位载荷不超过1.5 N、独立60 mm机械止挡。首轮测试加护目/夹点防护，并把指令时间限制在0.25–0.40 s。
- `TBD` 螺钉长度、打印材料、绳结/端接、回位弹性体、护罩和机器人安装接口；它们必须由实物尺寸与VAL-T04-006确定。

当前状态：用户明确“不对制造设备做要求”。因此不把任何特定设备作为硬约束；每个候选方案必须列出所需工艺、精度、外包依赖和替代工艺，之后再比较可实现性。
