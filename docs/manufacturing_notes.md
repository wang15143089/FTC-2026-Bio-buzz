## T06 锁紧件装配与验收（R53f / R53h）

- 适用对象: 换档夹紧链上的 16 件刚性定长限位环 `Ø8.0 / Ø5.7 x 6.0`（每档 16 件，套在弹簧**外面**），以及 M4 螺柱 + 尼龙锁紧螺母。
- 装配顺序（每条螺柱相同）: 螺柱 -> 内耳片 -> 侧板 -> 外耳片 -> 弹簧 -> **限位环（Ø8.0/Ø5.7 x 6.0）** -> 平垫 -> 尼龙锁紧螺母，**拧到螺母/平垫与限位环端面贴合即停**。
- 装配要点:
  - 拧到贴合即到底，**继续拧只压环、预载不再增长**（预载只由环长决定，不由力矩决定）。
  - 力矩上限 **1.0 N.m**；配尼龙锁紧螺母 + 螺纹胶 243 防松。禁止把限位环做长到超过弹簧自由长 8.4 mm 后再强拧。
  - 弹簧 k = 1.24 N/mm、自由长 8.4 mm、装配长 6.0 mm => 预载 **2.976 N/颗**（±0.2 mm 环长 => ±0.25 N）。
- 验收判据（台架）:
  - 预载 **2.976 ± 0.25 N/颗**（可用弹簧秤/压电片抽检）。
  - 两档夹口: pollen **64.0 mm** / nectar **86.0 mm**，偏差 **±0.5 mm**。
  - 台架 50 次来回后无衰减（预载、夹口仍在公差内）、限位环压缩永久变形 <= 0.1 mm。
  - 全程**无一次需要人工介入**结构（换档由已有 2000-0025-0002 完成）。
- 口径提醒（防误读）: 夹紧件单独保持力仅 **14.3 N/滑座**（mu = 0.30 名义），**挡不住发射反力峰值 37.5 / 81.3 N/滑座**；发射时守住夹口靠的是**通电的 25-2**（余量 3.0x / 4.8x）。详见 `docs/decision_log.md` V-0057。
- 状态: 几何 `pass`；装配与台架 `not_run`。
