# 验证计划

## 验证金字塔

1. L1 分析计算
2. L2 Python 数值模型
3. L3 二维或简化运动学模型
4. L4 简化三维碰撞/运动检查
5. L5 有明确必要性的物理仿真
6. L6 实体原型
7. L7 整机集成测试

只有较低层级不能回答工程问题时才升级；升级理由、模型边界和预期决策必须先记录。

## 阶段关口

| 阶段 | 最低退出证据 |
|---|---|
| M0 | 可测试需求、来源、优先级、开放问题和接口候选 |
| M1 | 多概念比较、选择理由、主要风险和粗略预算 |
| M2 | 可复算的载荷/速度/扭矩/功率/寿命计算及敏感性 |
| M3 | 简化参数几何、包络/行程/干涉检查 |
| M4 | 可重复生成的详细 CAD、接口和制造参数分离 |
| M5 | 模块级验收测试通过或偏差获批 |
| M6 | 相邻模块接口、传递功能和故障行为验证 |
| M7 | 整机任务、法规、功率、质量和碰撞验证 |
| M8 | 图纸/BOM/文件版本、制造检查和发布批准 |

## 验证记录要求

每项使用 `VAL-<模块>-NNN`，关联需求和接口；记录方法层级、输入版本、设备/脚本、边界条件、验收阈值、结果事实标签、证据路径、执行者和日期。`SIMULATED` 结果不得写成 `MEASURED`。
