# 系统架构

状态：Architecture Baseline v0.1；2026-09-19 经用户批准。条件模块仍由任务包选择决定，批准不等同于冻结任何具体机构。

## 系统边界

系统包括比赛机器人上的机械、电气、传感、控制软件及其接口。场地、比赛物体、操作员、充电/维护设备为外部系统。实际边界将在赛季和规则确认后冻结。

## 暂定功能链

`POLLEN/NECTAR → 获取 → 输送/可选识别与缓冲 → HIVE 发射或 FLOWER 顶部放置`，由移动平台、主结构、电源控制、感知定位和软件状态协调。GARDEN 留球与 PARK 主要由移动/物体控制功能完成。该功能链是候选集合，不是已选设计。

## 暂定模块分解

| ID | 模块 | 暂定目的 | 当前判断 |
|---|---|---|---|
| S00 | 系统工程与需求 | 需求、预算、接口、质量/功率/空间分配 | 保留，系统级 |
| T01 | 驱动与移动 | 在场地内支撑并移动机器人 | 暂定保留 |
| T02 | 主承力结构 | 提供基准、载荷路径、防护与通用安装 | 从原 T07 前移，减少接口倒置 |
| T03 | 电气、控制与传感安装 | 配电、控制器、线束、传感器和相机安装 | 扩展原 T08 |
| T04 | 比赛物体获取 | 从地面、FLOWER 底部或 LOADING ZONE 获取允许物体 | 条件模块，依任务组合决定 |
| T05 | 输送/缓冲/路由 | 在不超过 4 球控制上限下输送、暂存和可选识别/分流 | 暂合并；若接口或验证独立再拆分 |
| T06 | HIVE 发射 | 向朝上的 CELL 合法发射 POLLEN/NECTAR | 条件模块 |
| T07 | FLOWER 处理 | 从顶部放球；可选从底部取 POLLEN | 条件模块 |
| T08 | 控制与自主 | 模块状态协调、AUTO、传感与故障处理 | 保留为跨域系统模块 |
| T09 | 预留辅助功能 | 仅在方案证明存在独立任务时启用 | 当前不启用；BIOBUZZ 无独立攀爬末局机构需求 |
| T10 | 整机集成 | 管理包络、碰撞、质量、功率与装配集成 | 保留，集成级 |

T08 是系统级控制责任，不代表一个单独机械“盒子”；其代码与接口仍按 T01–T07 镜像组织。排序与存储暂并入 T05，因为规则把受控物体限制为 4 个，当前证据不足以支持独立模块。

## 待比较的任务组合（非机构方案）

| 包 | 功能范围 | 主要优点 | 主要风险/缺口 |
|---|---|---|---|
| P1 基础移动 | LEAVE、PARK、GARDEN 搬运 | 最低复杂度，适合作为底盘与自主基线 | 得分上限低，联盟贡献有限 |
| P2 FLOWER 专项 | P1 + 底部取 POLLEN + 顶部放 POLLEN/NECTAR | 低目标高度、可争夺 FLOWER 所有权 | 最后 60 s 时序、91 mm 开口与物体差异要求高 |
| P3 HIVE 专项 | P1 + 获取/输送 + HIVE 发射/TIP | 单次 TIP 分值高、直接关联 POLLINATOR RP | 发射一致性、动态 HIVE、场地公差和安全风险较高 |
| P4 双目标混合 | P1 + FLOWER + HIVE | 战术弹性与理论得分覆盖最高 | 模块/控制/功率/空间竞争，开发和验证成本最高 |

后续概念比较先比较任务包，再比较每个任务包的机构概念，避免把“任务选择”和“机构选择”混为一层。

## 设计先例使用原则

往届高水平 FTC 机器人用于发现成熟的功能模式、布局策略和失效经验；工业设计先例用于模块接口、载荷路径、可维护性、防错装、线束、护罩和制造简化。每个被采用的先例必须记录来源、提取的原则、当前赛季适用性、规则差异和自主验证结果。禁止仅因某队获奖就将其方案视为最优，也不直接复制未公开或无法验证的尺寸。

T01 底盘的轮距、轴距和四轮相对布局是冻结候选接口；在实测/STEP 测量完成前数值仍为 TBD。允许的最低限度拆分仅用于测量、维护、安装和不改变核心运动学布局的调整。

## 每个模块的最低定义

进入 M1 前，每个模块记录：目的、输入、输出、几何包络、安装接口、运动接口、电气接口、软件/控制接口、质量估算、功率需求、关键尺寸、依赖、失效模式和验证条件。

## 依赖原则

- T02 提供机械基准，但不得私自定义其他模块内部几何。
- T03 分配电源/端口/通信资源，各执行模块声明峰值与持续负载。
- T04–T09 只通过已登记接口交换物体、载荷、功率、信号和状态。
- T10 只集成已达到相应隔离验证关口的模块。

## 成熟度

M0 需求 → M1 概念 → M2 工程计算 → M3 简化几何 → M4 详细参数化 CAD → M5 隔离验证 → M6 子系统集成 → M7 整机集成 → M8 制造发布。任何跳级均需决策记录和风险接受。
