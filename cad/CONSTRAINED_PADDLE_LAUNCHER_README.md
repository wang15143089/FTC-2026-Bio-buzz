# 尺寸约束版：连续拨杆 + 对置飞轮发射机构

## 坐标与总成

- X–Y 平面为底盘安装平面，+Z 向上。
- 发射中心线相对底盘为 52°。
- 电机和舵机仅为包络；侧板、支架、通道、拨杆、轴、轮毂和飞轮均为实体零件。
- 模型不包含 POLLEN 或 NECTAR 实体。

## 飞轮间距调节机构

运动链为：舵机 12 mm 曲柄 → 65 mm 定长驱动杆 → 水平导向滑块 → 两根 110 mm 等长连杆 → 轴承座耳轴 → 上下飞轮轴。上下轴的两端均安装在开槽侧板外侧的滑动轴承座中，主动侧轴承座与连杆耳轴刚性连接；电机安装板也固定在对应移动轴承座上，因此调节过程中电机轴线不会与飞轮轴错位。

POLLEN 与 NECTAR 两个极限位置分别对舵机曲柄角、滑块位置和轴承座位置进行求解，不再采用悬空连杆示意。

## 送球逻辑

连续旋转舵机直接驱动三拨片转子。每转理论输送 3 件；25–40 rpm 对应 1.25–2.0 件/s。拨片由刚性臂、可更换横向叶片和柔性端条组成，后方两片单向柔性指抑制回滚。该方案不使用传送带。

## 输出

- `paddle_launcher_feasible_pollen.*`：POLLEN 间隙配置。
- `paddle_launcher_feasible_nectar.*`：NECTAR 间隙配置。
- `output/parts/`：开槽发射侧板、拨片、Sonic/Gecko 轮毂和送料侧板参考件。
- `paddle_launcher_feasibility_report.json/.md`：精确尺寸、运动学位置及实体干涉校核结果。

所有数值仍属于初步工程原型。加工前应根据实际轴承外径、舵机型号、轴肩/卡环位置和所选 goBILDA 轮毂的官方实物尺寸复核配合公差。
