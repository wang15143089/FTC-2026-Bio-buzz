# 归档：R38「扎带弹性夹口」分支（已作废，保留历史）

取代关系：本目录全部脚本 → 由 `simulation/mujoco/_work/r38_v8.py` 取代。

## 为什么作废

本目录的 r38_v3 / v4 / v5 / v6 / v7 及 `_r38_mk*/fix*` 把双飞轮夹口写成
「扎带（zip-tie）弹性浮动夹口」：`spring_patch()` 给两个滑座插入 slide 关节 +
刚度/预紧力/阻尼，并据此扫“每 mm 刚度”的甜点。该弹性件属于助手自行引入的
假设，无零件号、无尺寸、无来源。

用户 2026-10-12 指正：**调隙用的是已存在的真实调隙舵机方案**，不是扎带。

## 真实方案（读自仓库文件）

- 执行件：goBILDA `2000-0025-0002` 位置舵机；舵机盘 `1908-0025-0032`（25T，Ø32×6）；
  框架 `1802-0043-0001`。来源 `config/t06_launcher_cots.json`，
  审计 `docs/engineering/t06-opposed-flywheel-cots-audit.md:29-33`。
- 传动链：曲柄 12 mm → 定长拉杆 65 mm → 水平十字滑块 → 两根定长 110 mm 对角连杆
  → 两个轴承滑座耳片。位置：`cad/paddle_launcher_constrained.py:369-388, 404-431`。
- 对称性：十字滑块平移使两连杆对称开合，**中面位移恒为 0**，不依赖摩擦系数
  （`docs/p3_launcher_comparison.md:56`）。
- 两档：冷态半间距 NECTAR 89 / POLLEN 80，热态 89.8 / 80.8，使**运行夹口恒为 82 / 64**
  （`config/parameters.yaml`，DEC-0032）。曲柄 42.41° → 96.68°，切换只需转约 54°。

## 仍然有效的结论（与弹性假设无关，来自同一无扎带基线）

- 固定单一夹口无法同时发射两种球（夹口 82 时 POLLEN 轮面峰力仅 27.8 N、v=1.27；
  夹口 64 时 NECTAR 过不去）→ 这正是需要两档调隙的理由。
- 停位相位是决定性杠杆：叶片角 = ph0+30，甜点窗口 ph0 ∈ [120,160]。
- 托板 TRAY_X1 = 285 最好；初始球-球间隙不敏感。
